Exercise 13.1
Consider two LTI filters L1 and L2, and let α ∈C then the filter
L = αL1 + L2
(1)
is also an LTI filter.
Solution 13.1
Let {Xt}, {Yt} be sequences, and β ∈C, then
L [β {Xt} + {Yt}] = αL1 [β {Xt} + {Yt}] + L2 [β {Xt} + {Yt}]
= αβL1 [{Xt}] + αL1 [{Yt}] + βL2 [{Xt}] + L2 [{Yt}]
(linearity of LTI filters)
= βL [{Xt}] + L [{Yt}] .
Now for time invariance,
L [B [{Xt}]] = αL1 [B [{Xt}]] + L2 [B [{Xt}]]
= B [αL1 [{Xt}]] + B [L2 [{Xt}]]
(linearity of LTI filters)
= B [L [{Xt}]] .
Exercise 13.2
Consider two LTI filters L1 and L2. The filter L = L1L2, i.e. so that
L [{Xt}] = L1 [L2 [{Xt}]]
(2)
is also an LTI filter.
Solution 13.2
Let {Xt}, {Yt} be sequences, and α ∈C, then
L [α {Xt} + {Yt}] = L1 [L2 [α {Xt} + {Yt}]]
= L1 [αL2 [{Xt}] + L2 [{Yt}]]
= αL1 [L2 [{Xt}]] + L1 [L2 [{Yt}]]
= αL [{Xt}] + L [{Yt}] .
Now for time invariance
L [B [{Xt}]] = L1 [L2 [B [{Xt}]]]
= L1 [B [L2 [{Xt}]]]
= B [L1 [L2 [{Xt}]]] .
